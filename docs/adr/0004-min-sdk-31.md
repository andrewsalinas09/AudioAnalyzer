# ADR-0004: Minimum SDK 31 (Android 12)

- Status: Accepted
- Date: 2026-08-19

## Context

Candidates were API 26 (AAudio floor), 28 (stable AAudio/MMAP), and 31.
Early AAudio implementations (8.x, and to a lesser degree 9) carry
device-specific bugs that a measurement tool would have to detect and work
around — and a measurement app that silently measures wrong on old devices is
worse than one that refuses to install.

## Decision

`minSdk = 31` (Android 12) across all modules.

What API 31+ buys, concretely:

- Mature AAudio + MMAP implementations; far fewer per-device audio quirks.
- `ENCODING_PCM_24BIT_PACKED` / `PCM_32BIT` guaranteed in the platform API —
  relevant for 24-bit USB measurement mics (UMIK-2, iMM-6C).
- Better USB audio class handling and device routing behavior.
- Modern permission and storage models without compatibility branches.

## Consequences

- Devices on Android 8–11 are unsupported. Accepted: the target user
  (measurement) skews toward current hardware, and correctness beats reach.
- Code may assume API 31 features unconditionally; no `Build.VERSION` checks
  for anything at or below 31.
