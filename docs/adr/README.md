# Architecture Decision Records

Every significant technical decision gets an ADR: a short Markdown file
explaining the context, the options considered, the decision, and its
consequences. ADRs are numbered in order of acceptance and **never edited
after acceptance** — to change course, write a new ADR that supersedes the
old one and link both ways.

Template: [MADR](https://adr.github.io/madr/)-style — sections
*Context*, *Decision*, *Options considered*, *Consequences*.
